Como rodar na minha máquina?

Com Git e Node.js instalados, baixe o repositório e entre na pasta do projeto.

git clone https://github.com/iury-igd1/DAPL_2k26.git
cd DAPL_2k26

Na raiz do projeto, execute o comando do exercício escolhido. Para as duas simulações Express, instale as dependências uma vez antes de iniciar.

npm install --prefix 02-BackEnd/04-framework-express

Exemplo para o mini-blog

cd 02-BackEnd/02-endpoints/mini-blog
node app.js

Abra http://localhost:3006/ no navegador. Para encerrar, pressione Ctrl + C.
